📖 工具使用教程 (Wiki)

1. 基础操作

  • Series Config 加载：点击 📂本地加载 或 ☁️网络加载 加载主配置文件。
  • Level Config 加载：点击 📂本地加载 或 ☁️网络加载 上传关卡详情配置。加载成功后，列表会显示游戏名称并提供详情查看功能。
  • 配置集管理：支持多配置集 (base_global, base_us 等)，可通过下拉菜单切换，支持新建、复制、重命名、删除配置集。
  • 地区映射：设置不同地区 (Locale) 使用哪套配置，例如 US -> base_us，CN -> base_cn。

2. Series 编辑功能

  • 选择 Series：在 ID 选择器中切换不同的 Series ID (xl1, xl2 等) 进行编辑。
  • 基本属性：编辑 Order (排序) 和 Img (图片名) 字段。
  • 新增/删除 Series：通过相应按钮添加新的 Series 或删除当前选中的 Series。
  • 冲突检测：自动检测并显示重复的 ID，用 "(❌冲突)" 标记。

3. Levels 列表管理

  • 排序：支持鼠标拖拽重新排序，或使用右侧的 ↑↓ 按钮移动。
  • 查看详情：如果加载了 LevelCfg，点击列表项右侧的 ℹ️ 图标可查看该关卡的完整 JSON 信息（Path, Stages, Rule 等）。
  • 新增关卡：点击 "+ 新增一项" 按钮，支持单个或批量添加（逗号分隔）。
  • 删除关卡：点击右侧的 ✕ 按钮删除指定项。
  • 游戏名称显示：加载 LevelCfg 后，列表会显示关卡对应的游戏名称。

4. 批量编辑 (Bulk Edit)

  • 批量导入：支持从 Excel 或文本中粘贴 ID 列表（支持逗号、换行分隔）。
  • 智能合并：默认模式将新 ID 置顶，旧 ID 自动顺延，避免数据丢失。
  • 覆盖模式：勾选 "覆盖现有列表" 后，完全替换现有列表。
  • 加载当前列表：点击 "加载当前列表" 可将现有数据填充到编辑框中。

5. 云端功能

  • 网络加载：通过 Cloudflare Worker 从远程 Gist 加载配置文件。
  • 保存到网络：编辑完成后可保存到远程 Gist，支持自动链式加载 SeriesCfg 和 LevelCfg。
  • 设置管理：首次使用时需要配置 Worker URL 和访问密码。
  • 状态指示：通过颜色状态点显示本地/远程加载状态（绿色=成功，红色=失败）。

6. 数据管理

  • 导出 JSON：点击 "📤 导出 JSON" 下载完整的配置文件。
  • 复制 JSON：点击 "📋 复制" 将完整配置复制到剪贴板。
  • 格式兼容：自动检测并转换旧版数组格式到新版结构 (configs + mapping)。
  • 未保存提醒：有未保存修改时，标题栏显示 "*" 号，关闭页面时会提醒保存。

7. 界面特性

  • 粘性工具栏：滚动时工具栏自动吸附顶部，方便操作。
  • 卡片式布局：Series Config 和 Level Config 采用卡片设计，状态清晰。
  • 响应式设计：适配不同屏幕尺寸，支持移动端操作。
  • 回到顶部：滚动超过 300px 时显示浮动按钮。
